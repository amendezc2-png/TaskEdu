## Descripción del Proyecto
TaskEdu es un Producto Mínimo Viable (MVP) diseñado para que los estudiantes registren sus actividades académicas, consulten fechas de entrega, controlen el estado de sus tareas (pendientes o terminadas) y filtren según su avance.
